# E2E чеклист в Telegram

Требуется заполненный `TELEGRAM_BOT_TOKEN` и `ALLOWED_USER_IDS` в
`/home/user/.config/opencode/telegram-bot.env`, запущенная служба
`opencode-telegram-bot` и живой сервер OpenCode.

1. `/start` - приходит меню, все кнопки отвечают.
2. «Новая задача» -> проект `/tmp/opencode/bot-e2e` -> модель по умолчанию ->
   текст «Ответь одним словом: ок». Приходит сообщение о запуске, затем
   прогресс и финальный ответ.
3. В той же сессии отправить «Прочитай файл /tmp/opencode/bot-e2e/hello.txt».
   Должен прийти запрос прав с кнопками; нажать «Разрешить». Задача
   продолжается.
4. Создать вторую задачу и попросить `sleep 120`. В первой сессии отправить
   текст: появляется выбор «В очередь», «Вклиниться», «Отмена». Проверить все
   три варианта на разных прогонах.
5. Дождаться завершения второй задачи в фоне: приходит уведомление с итогом и
   кнопкой «Открыть сессию». Открыть - карточка сессии.
6. Включить «Все сессии: вкл» в списке, завершить задачу в сессии, начатой на
   десктопе - приходит уведомление.
7. Запросить у бот-сессии действие, требующее прав, и ответить на него на
   десктопе. Сообщение в боте меняется на «Уже решено на десктопе».
8. Остановить выполняющуюся задачу кнопкой «Стоп» - статус меняется на
   завершенный.
9. Удалить сессию: подтверждение, затем она исчезает из списка.
10. «Сервис» -> «Перезапустить» -> подтверждение. Приходит сообщение об
    успешном перезапуске; список сессий снова работает.
11. Перезапустить бота (`systemctl --user restart opencode-telegram-bot`) при
    висящем запросе прав: сообщение с кнопками не дублируется, ответ работает.
12. Проверить секреты:
    `journalctl --user -u opencode-telegram-bot --no-pager | grep -F "$TELEGRAM_BOT_TOKEN"`
    не должен ничего найти; пароль OpenCode тоже.
13. Отправить в активную сессию голосовое «Ответь одним словом: ок».
    Приходит «🎤 ...» с расшифровкой, затем ответ сессии. В журнале нет
    ошибок распознавания.
14. На шаге ввода пути («Другая папка») отправить голосовое. Должен прийти
    вежливый отказ, состояние ввода пути сохраняется.
15. Отправить голосовое при занятой сессии. Появляются кнопки «В очередь»,
    «Вклиниться», «Отмена», текст черновика - распознанная фраза.
